  # Design: Local-First Research Knowledge Base

  ## Technical Approach

  Build a Python CLI to validate Git records, derive a multigraph/search index, and export HTML. Engram holds SDD only;
  Git is scientific truth; external assets are immutable references.

  curate → validate → promote → build graph/index → query/export

  ## Architecture and Repository Structure

  pyproject.toml
  src/semillero_kb/{cli,models,validation,ingest,curation,graph,search,visualization}.py
  schemas/{records,relations,locators}.json
  research/
    sources/{records/,bibliography.csl.json}
    claims/{records/,evidence/}
    graph/{entities/,relations/}
    experiments/{experiments/,results/}
    corpus/{seed-manifest.yaml,expansion-log.yaml}
    assets/{datasets.yaml,repositories.yaml,external.yaml}
    taxonomy/{domains.yaml,roles.yaml,relations.yaml}
  build/{graph.json,search.sqlite,index.html}
  tests/{unit,integration,fixtures,acceptance}/

  build/ is reproducible and ignored; research/ is canonical, with one YAML record per stable ID.

  ## Seed Scientific Corpus

  Seeds require seed=true, source_role, domain, provenance, verification status, and admission state:

  human_seed | verified_expansion | candidate.

  Roles:

  foundational, seminal, review, methodological, application, benchmark, state_of_the_art, contradictory_evidence,
  supporting.

  Guide papers anchor relevance, not truth. Expansion is admitted only after identity, scope, locator, access/license,
  and relevance checks.

  The three domains remain separate:

  - Surface water.
  - Groundwater potential.
  - Geothermal prospectivity.

  Shared foundations include EO, remote sensing, GIS, image processing, geology, hydrogeology, geophysics, probability,
  statistics, optimization, PDEs, fluid flow, heat transfer, ML, DL, CNNs, transformers, PINNs, and EO foundation
  models.

  ## Ingestion, Expansion, and Verification

  1. Register manual or guide metadata as candidate.
  2. Deduplicate using persistent ID plus version.
  3. Validate structure, identity, access, license, checksum, and domain firewall.
  4. Curator inspects the source and typed locator.
  5. Record assessment; candidates cannot self-promote.
  6. Expand only bounded batches from citations, citing works, reviews, related groups, datasets, repositories, or
     recent work linked to existing claims/concepts.

  7. Log parent, query, date, cap, and decision.
  8. Never expand unverified candidates.
  9. Build graph, search index, and HTML from canonical records.

  ## Search, Visualization, Experiments, and Assets

  SQLite FTS5 indexes titles, statements, IDs, domains, roles, and lifecycle. Queries return neighbors, provenance,
  contradictions, and subgraphs.

  PyVis exports self-contained HTML with zoom, search, filters, colors, centrality/role sizing, and navigation to
  papers, datasets, repositories, foundations, state-of-the-art records, and gaps.

  Assets and repositories store URI, version/tag/commit, acquisition date, license, availability, optional local path,
  and checksum. V1 never downloads or clones automatically.

  Experiment manifests reconstruct inputs → results → claims and preserve positive, negative, inconclusive, and failed
  outcomes.
